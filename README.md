## Overview

Equipment and Quick Slots adds six dedicated equipment slots to Valheim's inventory for armor, cape, and utility items, plus four quick-use hotbar slots for consumables and tools, freeing up regular inventory space and enabling faster item access during combat. The equipment slots support all modded armor and accessory items.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Equipment and Quick Slots** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **6 Equipment Slots** | Dedicated slots for helmet, chest, legs, cape, and utility items |
| **4 Quick-Use Slots** | Hotbar quick slots for potions, food, and frequently used items |
| **Inventory Freedom** | Equipment no longer occupies regular inventory grid space |
| **Mod Item Support** | Equipment slots work with all custom armor added by other mods |
